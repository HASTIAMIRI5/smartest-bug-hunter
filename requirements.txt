# smartest-bug-hunter

A practical OWASP-focused security detector app for scanning public or local web targets and surfacing OWASP Top 10 style findings. It is designed as a learning-oriented security dashboard and works well for designing demo workflows, reporting risk, and exploring web app security signals.

## Features

- OWASP Top 10 inspired checks across A01-A10
- Security headers and cookie validation
- Login/auth simulation and credential flow checks
- Risk score and summary reporting
- Vulnerability history stored locally in SQLite
- CSV and JSON report export
- Dark and light dashboard themes
- Docker support for local deployment

## Quick start

### Local Python setup

1. Create and activate a virtual environment
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

2. Install dependencies
   ```bash
   pip install -r requirements.txt
   ```

3. Run the app
   ```bash
   python app.py
   ```

4. Open your browser at:
   ```text
   http://localhost:5000
   ```

### Docker

```bash
docker build -t smartest-bug-hunter .
docker run -p 5000:5000 smartest-bug-hunter
```

## What the app checks

- Broken access control and sensitive URL parameters
- HTTP/HTTPS and crypto policy issues
- Injection patterns and unsafe sink detection
- Security misconfiguration and missing headers
- Vulnerable component detection heuristics
- Authentication weaknesses and cookie protections
- Data integrity and external resource review
- Logging and debug leakage detection
- SSRF risk indicators

## Security note

This project is for authorized testing and educational use only. It does not replace a professional audit, red team assessment, or vulnerability management process.
